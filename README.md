# Animated Facts Studio

A free-first animated facts video studio.

## Goal

Enter one topic and generate a short animated explainer with:
- Researched facts and script
- 2D cartoon animation
- Narration
- Subtitles
- Downloadable MP4

## Target setup
- Android-friendly workflow
- 1080p video
- Free/open-source tools where possible
- GitHub Actions for cloud rendering
